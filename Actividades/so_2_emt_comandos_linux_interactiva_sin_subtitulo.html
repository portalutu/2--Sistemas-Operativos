01Propósito de la clase

La terminal permite administrar un sistema Linux con precisión. En lugar de memorizar comandos sueltos, conviene entender qué problema resuelve cada comando, qué información devuelve y cuándo conviene usarlo.

Diagnóstico
¿Qué tiene el equipo?
uname, os-release, free, df, uptime.
Operación
¿Dónde estoy?
pwd, ls, cd, cat, less, tail.
Administración
¿Qué está pasando?
ps, top, journalctl, dmesg, lsof.
Red
¿Tengo conectividad?
ip, ping, dig, ss, tcpdump.

05Árbol de directorios y navegación

Linux organiza el sistema desde una raíz única: /. La navegación con cd, pwd y ls solo tiene sentido si se comprende este árbol.

06Permisos de archivos: chmod visual

Los permisos se dividen en usuario, grupo y otros. Cada permiso tiene valor numérico: lectura = 4, escritura = 2, ejecución = 1.

r
w
x
Resultado chmod
755
rwxr-xr-x
ejemplo
chmod 755 archivo
Precaución: evitar usar chmod 777 sin justificación. Da acceso total a todos los usuarios.
07Procesos y monitoreo

Un proceso es un programa en ejecución. Linux permite listarlos, observar consumo, enviarlos a segundo plano o finalizarlos.

Listar
ps -ef
Muestra todos los procesos.
Monitorear
top / htop
CPU, memoria y procesos activos.
Finalizar
kill PID
Envía una señal a un proceso.
08Comandos de red y diagnóstico

Para diagnosticar red se sigue una secuencia: interfaz, IP, ruta, DNS, conectividad y puertos.

09Editores de texto: nano y vim

En administración Linux se editan archivos de configuración. Nano es más simple para empezar; Vim es más potente pero requiere modos.

Nano
Atajos esenciales
Ctrl+O guardarCtrl+X salirCtrl+W buscarCtrl+K cortarCtrl+U pegar
Vim
Comandos esenciales
i insertarEsc normal:w guardar:q salirdd borrar línea
Recomendación para estudiantes
Para una primera práctica, usar nano. Para comprender administración profesional, introducir Vim mostrando la diferencia entre modo normal, inserción y comandos.
